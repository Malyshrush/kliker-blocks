# Kliker Blocks 1.2.6

- Новое меню «База графов» содержит семь сценариев с подсказками и тестовыми файлами. Разделы: «Экран и снимки», «Тренировка и памятки», «Наблюдение».
- Из базы открывается рабочая копия в папке «Документы / Kliker Blocks / Graph Library». Графы также доступны отдельным архивом.
- Исправлено падение экранного меню после выбора области. Меню возвращается с путём к PNG; отмена и ошибка сохраняют последний удачный снимок.

Вариант x86 проверен на 64-разрядной Windows в режиме совместимости.

# Kliker Blocks 1.2.6 in English

- The Graph library menu contains seven examples organized into Screen and screenshots, Practice and guides, and Monitoring. Examples include sample files, localized graph prompts and setup instructions.
- The app opens a working copy under Documents / Kliker Blocks / Graph Library. A standalone graph archive is available.
- Fixed the screen menu crash after selecting an area. The menu reopens with the PNG path. Cancelling or an error keeps the last successful screenshot.

The x86 build was verified on 64-bit Windows using its compatibility layer.
