# Kliker Blocks 1.3.1

Редактор снимков поддерживает закрепление снимка как заметки поверх окон, непрозрачное скрытие области, отдельный цвет контура и цвет с прозрачностью заливки фигур. Два снимка одинакового размера можно сравнить и сохранить результат с выделенными изменениями. Блок «Прочитать QR- или штрихкод» локально читает первый код из файла или с рабочего стола.

В закреплённой заметке можно изменить масштаб изображения, перетащить его, добавить текст и сохранить файл .klnote.

Редактор снимка получил цветные кнопки. Значки отмены действия, перемещения панели, закрепления, сохранения и закрытия расположены сбоку от выделения. Нижняя панель занимает высоту инструментов и видимой подсказки. На панелях курсор принимает вид обычной стрелки. При выборе блока его свойства показываются после подготовки всех полей.

Для Windows доступны x64 и x86. Сборка x86 проверена на 64-разрядной Windows в режиме совместимости.

# Kliker Blocks 1.3.1

Pin screenshots as notes above other windows, cover an area with opaque color, and choose separate outline and fill colors and fill opacity for shapes. Compare equal-size images and save the highlighted differences. The Read QR or barcode block decodes the first code locally from a file or the desktop.

Zoom and drag the image in a pinned note, add text, and save it as a .klnote file.

The screenshot editor uses colored buttons. Undo, move toolbar, pin, save and cancel appear beside the selection as icons. The drawing toolbar fits its controls and visible hint. Both toolbars use the standard arrow pointer. Selecting a block shows its properties once all fields are ready.

Windows x64 and x86 builds are included. The x86 build was tested on 64-bit Windows using its compatibility layer.
