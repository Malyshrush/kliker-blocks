# Kliker Blocks 1.3.0 — выпуск

Верхнее меню стало компактнее: захват и запись макросов находятся в «Инструментах», назначения мыши и языки — в «Настройках»; демонстрация, сайт и поддержка доступны через «Справку». При уменьшении главного окна свойства блока и кнопка открытия журнала в отдельном окне остаются доступными. Список блоков можно свернуть. Минимальный размер окна — 1000 × 650 пикселей с учётом масштабирования Windows.

# Kliker Blocks 1.3.0 — Release

The top menu is more compact: capture and macro recording are under Tools, mouse mappings and languages under Settings; the demo, website and support are under Help. Block properties and the journal pop-out stay accessible as the main window narrows. The block palette can be collapsed. The minimum window size is 1000 × 650 pixels subject to Windows scaling.

The x86 build is tested on 64-bit Windows using compatibility.
