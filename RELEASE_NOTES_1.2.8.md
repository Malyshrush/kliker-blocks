# Kliker Blocks 1.2.8

Добавлены четыре блока для подсчёта символов в тексте и файлах и для редактирования строк и текстовых файлов. Поддерживаются фильтры символов, выбор строк и диапазонов, сохранение результата в копию и удаление пустых, пробельных и повторяющихся строк по условиям. Поддерживаются UTF-8, UTF-16 и Windows-1251, предел 8 МиБ.

Исправлены открытие заметок из проводника, имя сохранённой заметки и отслеживание изменений. Состояние заметок восстанавливается при открытии.

# Kliker Blocks 1.2.8

Four blocks count characters in text and files and edit lines or text files. They provide character filters, line ranges, output copies, and deletion of empty, whitespace-only and repeated-character lines. UTF-8, UTF-16 and Windows-1251 are supported; limit 8 MiB.

Fixed opening notes from Explorer, the saved note title and change detection. Saved note state is restored when opened.

The x86 build is tested on 64-bit Windows using compatibility.
