# Kliker Blocks 1.1.6

## Русский

- Исправлен запуск сценариев с блоками «Запросить текст», «Вопрос с кнопками» и «Выбрать вариант», когда X, Y, ширина и высота окна оставлены пустыми.
- Пустые X и Y размещают диалог по центру экрана. Для точной позиции укажите обе координаты.
- Пустые ширина и высота подбираются под вопрос и варианты. В свойствах и справке указаны допустимые размеры: ширина 360–3000 пикселей; минимальная высота — 185 для ввода, 180 для вопроса с кнопками, 260 для выбора варианта; максимальная высота — 3000.
- В меню «Справка» добавлена ссылка на сайт и сообщество Kliker Blocks. На сайте доступны поиск по блокам и копируемые графы примеров.
- Добавлен раздел «Поддержать проект» в главном меню, справке, окне «О программе», компактной панели и трее. В нём показаны пять предоставленных автором QR-кодов: USDT в сетях TON, TRC20, ERC20, Solana и Сбербанк. Поддержка добровольна.
- Сборка, самотесты, практическая проверка диалогов и аудит английской локализации выполнены перед публикацией.

## English

- Fixed scenario launch with Text prompt, Button question and Choose option blocks when window X, Y, width and height are blank.
- Blank X and Y center the dialog on screen. Enter both coordinates for an exact position.
- Blank width and height grow to fit the prompt and choices. Properties and Help show the limits: width 360–3000 px; minimum height 185 for text input, 180 for button question and 260 for option picker; maximum height 3000 px.
- Help now links to the Kliker Blocks website and community. The site has a searchable block catalog and copyable example graphs.
- Added a voluntary Support the project section to the main menu, Help, About, compact panel and tray. It shows five author-supplied QR codes: USDT on TON, TRC20, ERC20 and Solana, plus Sberbank.
- Build, self-tests, practical dialog checks and English localization audit passed before publication.
