# Kliker Blocks 1.1.7

## Русский

- На [GitHub](https://github.com/Malyshrush/kliker-blocks/releases/tag/v1.1.7) доступны отдельные установщики и переносимые самодостаточные ZIP-сборки для Windows x64 и x86.
- Для 64-разрядной Windows рекомендуется x64. На 32-разрядной Windows используйте x86. Установщики проверяют совместимость архитектуры; x86 также может работать на x64 через Windows.
- На контуре блока синяя точка входа по умолчанию находится сверху слева, красные выходы — снизу справа. Связи со стрелкой обходят блоки. Для каждой связи настраиваются наконечник, рисунок линии, цвет, прозрачность и толщина.
- Для каждого блока можно выбрать форму, цвет и прозрачность заливки и окантовки, а также отдельно поставить вход и выходы на контур. Оформление применяется к одному блоку либо сохраняется как стандарт для данного типа во всей программе. Индивидуальные настройки сохраняются в проекте и коде графа.
- Программа, встроенная справка, окно «О программе», сайт и страница GitHub поясняют выбор архитектуры и новые настройки редактора.
- Сборки x64 и x86, самотесты, аудит английской локализации и установка/удаление проверены на доступной 64-разрядной машине. Проверка на отдельной 32-разрядной Windows пока не проводилась.

## English

- Separate Windows x64 and x86 installers and self-contained portable ZIPs are available on [GitHub](https://github.com/Malyshrush/kliker-blocks/releases/tag/v1.1.7).
- Choose x64 for 64-bit Windows and x86 for 32-bit Windows. Installers check architecture compatibility; x86 can also run on x64 Windows through Windows compatibility support.
- Blue input ports default to the upper-left outline; red outputs default to the lower-right. Arrow connections route around blocks. Each link can have its own end marker, line pattern, color, opacity and width.
- Each block can have a rectangle, rounded rectangle, square, circle or diamond shape, custom fill and border, and individually positioned ports on its outline. Apply the appearance locally or save it as the default for that block type. Local settings survive project and graph-code round trips.
- The app, built-in Help, About dialog, website and GitHub page explain architecture selection and the new editor controls.
- x64 and x86 builds, self-tests, English localization audit and installer install/uninstall were checked on an available 64-bit machine. A separate 32-bit Windows machine has not yet been tested.
