# Kliker Blocks 1.2.7

- В журнале можно выделить фрагмент мышью и скопировать через Ctrl+C. Ctrl+A выделяет все отображаемые записи. Те же команды доступны в отдельном окне.
- Кнопка 📁 в свойствах открывает выбор файла, папки или пути сохранения. Поле остаётся редактируемым.
- Кнопка $x перечисляет переменные текущего графа и показывает, где они используются. В текстовом поле выбор color вставляет ${color} в позицию курсора.
- Подписи блоков рисуются целыми строками. Полный текст доступен при наведении на блок.

Сборка x86 проверена на 64-разрядной Windows в режиме совместимости.

# Kliker Blocks 1.2.7 in English

- Select and copy fragments of the execution journal with Ctrl+C. Ctrl+A selects all displayed entries. Both shortcuts work in the detached journal.
- Use the folder button to browse for a file, folder or output path. You can still type the path.
- Use $x to insert a variable from the current graph and see where it is used. Selecting color inserts ${color} at the cursor in a text field.
- Block captions render full lines. Hover over a block to read its full caption.

The x86 build was tested on 64-bit Windows using the compatibility layer.
